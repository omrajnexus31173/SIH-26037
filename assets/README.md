# Assets

- `sample_road.jpg`: Ultralytics `bus.jpg` sample used for local perception smoke tests. It contains real objects so YOLO inference can be verified without hardware.
- `demo_drive.avi`: generated by `scripts/generate_demo_video.py`. It is a short sample-derived clip with **synthetic camera motion**, not a real driving recording. It provides an honest fallback when no physical phone/webcam is available. The dashboard labels synthetic sources explicitly.

No external 3D model assets are required. The 3D simulator builds procedural vehicles, pedestrians, buildings, trees, signs and road geometry in the frontend.
